# Escolhas que Protegem

Website educativo sobre o consumo de álcool e drogas entre estudantes.

## Ficheiros do projecto

- `index.html` — estrutura e conteúdo do website.
- `style.css` — apresentação visual, cores, tipografia e adaptação a telemóveis.
- `script.js` — funcionamento do menu em dispositivos móveis.

## Abrir no computador

Abra o ficheiro `index.html` num navegador (Chrome, Firefox, Edge, etc.).

## Publicar gratuitamente com GitHub Pages

1. Entre em https://github.com e inicie sessão.
2. Crie um repositório novo, por exemplo `escolhas-que-protegem`.
3. Escolha a opção **Public**.
4. Carregue os três ficheiros principais (`index.html`, `style.css` e `script.js`) para a raiz do repositório. Também pode carregar este `README.md`.
5. No repositório, abra **Settings → Pages**.
6. Em **Build and deployment**, escolha **Deploy from a branch**.
7. Seleccione a branch `main` e a pasta `/(root)`; carregue em **Save**.
8. Aguarde a publicação. O GitHub Pages apresentará um endereço semelhante a `https://SEU-NOME.github.io/escolhas-que-protegem/`.

O endereço exacto só fica disponível depois de activar o GitHub Pages no seu repositório.

## Personalização antes da entrega

- Acrescente, se necessário, o nome da escola, disciplina, turma, classe e docente.
- Confirme a grafia dos nomes dos membros do grupo.
- Se o professor solicitar pesquisa própria, apresentem apenas resultados agregados de questionários anónimos, sem nomes ou dados pessoais.

## Nota

O website utiliza uma fonte tipográfica externa do Google Fonts. Se a ligação à Internet não estiver disponível, o navegador usará fontes alternativas.
